Tickmarks plug-in for Adobe Acrobat
===================================

INSTALL (each PC, needs admin rights)
1. Unzip this folder.
2. Close Acrobat.
3. Double-click Install.cmd and click Yes on the Windows admin prompt.
4. Start Acrobat. Open All tools > Tickmarks (use "View more" if it isn't listed yet).

USING IT
- Symbols, Numbers, Letters, Add Note: click the button, then click on the page.
  Each click places a mark. Press Esc or pick another tool to stop.
- The small arrow on Symbols picks which symbol. The arrow on Numbers/Letters lets you
  set the next value, turn Auto-Increment on or off, and reset counters.
- Color and Size apply to marks placed from then on. Any mark can be resized by
  selecting it and dragging a corner.
- To move or delete a mark, click it with the Tickmarks tool (or Select tool) and drag,
  or press Delete.
- Settings are remembered after restarting Acrobat.
- Marks are standard PDF stamps: they show and print on any computer.

IF IT DOESN'T SHOW UP
- Acrobat > Menu > Preferences > General: make sure "Use only certified plug-ins" is OFF.
- Run Install.cmd again and check the window for errors.

UNINSTALL
Close Acrobat and double-click Uninstall.cmd.
